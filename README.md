# AlcoVanish

Клиентский мод для **Minecraft Java 26.2** на Fabric. Подсвечивает руды, блоки, игроков и мобов, добавляет игровые HUD и помогает заполнять таблички. Меню настроек открывается клавишей **K**.

## Установка

1. Установи Minecraft Java 26.2 с Fabric Loader 0.20.1 или новее и Java 25.
2. Помести Fabric API для 26.2 и собранный `AlcoVanish-26.2-beta.jar` в папку `mods`. Mod Menu можно поставить для доступа к настройкам из списка модов.
3. Запусти игру и открой настройки AlcoVanish. Используй клиентские функции там, где это разрешено правилами сервера.

## Возможности

### Руды и блоки

- **Руды.** Можно выбрать сразу несколько типов или включить все. Поддерживаются уголь, железо, медь, золото, редстоун, алмазы, лазурит, изумруды, кварц и незеритовые обломки. Учитываются глубинные варианты, где они есть, и золотая руда Нижнего мира.
- **Блоки.** Отдельные переключатели для сундуков (обычных, ловушек и эндер-сундуков) и для механизмов и редстоуна. Вторая группа охватывает, например, поршни, наблюдатели, воронки, повторители и компараторы.
- Дальность для руд и блоков задаётся отдельно. Доступны значения от 1 до 64 блоков и режим «Бесконечно» в пределах чанков, загруженных клиентом. Серверные правила и данные, которые сервер отправляет клиенту, определяют, что можно отобразить.

### Игроки и мобы

- **Подсветка игроков.** Контуры загруженных игроков видны за препятствиями. Можно задать радиус и распределить ники по красному, зелёному и фиолетовому спискам.
- **Подсветка мобов.** Свой переключатель, клавиша и радиус. Фильтры включают всех, дружелюбных, враждебных и боссов.
- **Игроки рядом.** HUD показывает ники в выбранном радиусе и при желании расстояние. Настраиваются число строк, размер, положение и непрозрачность панели. Значки невидимости и отсутствия записи в Tab описывают данные клиента. По ним нельзя подтвердить режим vanish.
- **Счётчик мобов.** Панель группирует ближайших мобов по типам и показывает количество каждого. Настраиваются фильтр, положение, масштаб, непрозрачность и мягкость края.
- **Здоровье.** Для игроков и мобов можно отдельно выбрать выключение, показ при наведении или постоянный индикатор над существом. Доступны сердца и полоска, настройки позиции и размера панели цели, высоты и масштаба надголовных индикаторов.

### Таблички

- Именованные наборы четырёхстрочных шаблонов с предпросмотром и проверкой ширины. Наборы можно создавать, переименовывать, удалять, импортировать и экспортировать через `config/alcovanish-signs.json`.
- Режим заполняет доступные таблички в пределах обычной дальности взаимодействия. Текст отправляется после разрешения редактирования от сервера. Из подходящих шаблонов выбирается случайный с предпочтением текста, отличающегося от соседних табличек.
- При входе в мир режим выключен. **Shift** временно приостанавливает заполнение. Доступны параметры перезаписи, задержки, ожидания ответа и числа попыток.
- Команды: `/signs`, `/signs on`, `/signs off`, `/signs reset`, `/signs reload`.

### Личные сообщения

Для серверов, где это разрешено, можно вручную запустить или остановить очередь личных сообщений по серверному списку игроков. Настраиваются текст, исключения по никам, пауза между сообщениями и клавиша запуска.

## Управление

| Клавиша по умолчанию | Действие |
| --- | --- |
| **K** | Открыть настройки |
| **G** | Переключить подсветку игроков |
| **V** | Переключить подсветку блоков и руд |
| **H** | Переключить заполнение табличек |
| **N** | Показать или скрыть список игроков рядом |

Клавиши переназначаются в настройках. Для подсветки мобов и очереди сообщений клавиши можно назначить вручную. Конфигурация хранится в `config/alcovanish.json`.

## Сборка из исходников

Нужны **JDK 25** и **Gradle 9.8.2**. Из корня репозитория запусти:

```sh
gradle build
```

Готовый файл находится по пути `build/mods/AlcoVanish-26.2-beta.jar`.
