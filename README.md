# AlcoVanish

AlcoVanish — клиентский мод для Minecraft Java 26.2 на Fabric. Он добавляет подсветку игроков, мобов и блоков, настраиваемые элементы игрового экрана, заполнение табличек по шаблонам и автоматический выбор инструмента из хотбара.

Настройки собраны в одном меню. Каждый модуль можно настроить отдельно, а элементы HUD можно перемещать прямо на экране предпросмотра.

## Как начать

1. Установи Minecraft Java **26.2**, Fabric Loader **0.20.1 или новее** и Fabric API для этой версии игры.
2. Положи `AlcoVanish-26.2-beta.jar` в папку `mods` своего профиля Fabric.
3. Зайди в мир и нажми **K**, чтобы открыть меню AlcoVanish. Если установлен Mod Menu, меню также доступно через шестерёнку у мода.

Клавишу **K** можно переназначить в меню мода или в настройках управления Minecraft.

## Что есть в моде

| Вкладка | Возможности |
| --- | --- |
| **Таблички** | Заполняет ближайшие доступные таблички четырёхстрочными шаблонами. Можно хранить несколько наборов, смотреть предпросмотр и переносить наборы между профилями. |
| **Игроки** | Показывает контуры игроков с цветами по никам и список ближайших игроков с расстояниями. |
| **Мобы** | Подсвечивает мобов по категориям и выводит счётчик с разбивкой по видам. |
| **Блоки** | Отмечает сундуки, редстоун и выбранные виды руд. Дальность для блоков и руд настраивается отдельно. |
| **Рассылка** | Отправляет один текст по очереди игрокам из списка сервера с заданной паузой и исключениями. Использует команду `/m`. |
| **HP** | Показывает здоровье игроков и мобов при наведении или над сущностью. Доступны сердца и полоса. |
| **Доп. опции** | Автоподбор инструмента, автототем после срабатывания, ночное зрение, отключение тумана и затемнения от вардена, счётчик сломанных контейнеров. |

Подсветка использует блоки и сущности, данные о которых клиент уже получил. На сервере возможность редактировать таблички и отправлять личные сообщения зависит от прав игрока и настроек сервера.

## Сборка из исходников

Установи **JDK 25**. Укажи путь к нему через `JAVA_HOME` или добавь его папку `bin` в `PATH`. Gradle Wrapper скачает **Gradle 9.8.2** и проверит SHA-256 дистрибутива. На первом запуске понадобится интернет для загрузки Gradle и зависимостей. Отдельная установка Gradle и папка `.build-toolchain` не нужны.

**Windows (PowerShell)**

```powershell
.\gradlew.bat clean build
```

**Linux**

```sh
./gradlew clean build
```

Запускай команды из корня проекта. Готовый мод появится в `build/mods/AlcoVanish-26.2-beta.jar`.
