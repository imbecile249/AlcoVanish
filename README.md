# AlcoVanish

Клиентский Fabric-мод для Minecraft Java 26.2. В Mod Menu открой шестерёнку мода, чтобы настроить таблички, список игроков, подсветку блоков и личные сообщения.

## Таблички

Поведение перенесено по функциям из приложенного мода: мод выбирает ближайшую доступную табличку в пределах дальности взаимодействия игрока, не открывает экран редактора, назначает ей шаблон, подходящий по ширине строк, и отправляет текст только после того, как сервер разрешил редактирование. Вощёные таблички и таблички с командами при клике пропускаются. Удерживай Shift, чтобы временно приостановить обход.

В настройках каждая запись списка соответствует одной табличке; четыре поля соответствуют четырём строкам таблички. На странице показано семь записей, а нумерация продолжается на следующих страницах. Шаблоны применяются в порядке списка по кругу: после последней подходящей записи выбор продолжается с начала. Пустые и не помещающиеся по ширине записи пропускаются. Доступны задержка между действиями, таймаут ответа, максимум попыток, поворот взгляда к табличке и перезапись уже совпадающего текста. Начальные значения задержки — 400–900 мс, таймаута — 20 тиков, попыток — 2. Клавишу режима можно менять прямо во вкладке. Команда `/signs` показывает состояние; доступны `/signs on`, `/signs off`, `/signs reset` и `/signs reload`.

## Остальные функции

- По умолчанию `G` включает подсветку других загруженных игроков сквозь стены.
- По умолчанию `H` включает автоматическое заполнение табличек.
- По умолчанию `N` показывает или скрывает список игроков рядом. По умолчанию список расположен сверху по центру; в настройках можно менять смещение относительно центра и верхнего края.
- По умолчанию `V` включает подсветку блоков. Во вкладке «Блоки» дальность подсветки блоков и руд настраивается отдельно. Для обоих ползунков доступны от 1 до 128 блоков и режим «Бесконечно» в пределах загруженных чанков.
- Во вкладке блоков есть отдельный переключатель руды: выкл., уголь, железо, золото, редстоун, алмазы, незеритовые обломки, кварц, изумруд или лазурит. Для руд, которые встречаются в глубинном сланце, подсвечиваются оба варианта. Дальность подсветки руд настраивается отдельным ползунком.

Клавишу каждого модуля можно переназначить в его вкладке настроек. Вкладка личных сообщений позволяет назначить клавишу для запуска и остановки очереди; по умолчанию эта клавиша не назначена.

Подсветка блоков охватывает только чанки, загруженные клиентом в пределах текущей дальности прорисовки.

## Личные сообщения

Во вкладке «Личные сообщения» можно задать один текст, указать интервал и вручную запустить очередь команд `/m ник сообщение` для имён из серверного списка игроков. Очередь можно остановить кнопкой в любой момент. Начальный интервал — 1500 мс; серверные античит-пороги зависят от конкретного сервера, поэтому настройка служит ограничением частоты, а не гарантией обхода его правил.

Настройки хранятся в `config/alcovanish.json`. При первом запуске существующий `config/nearby-workshop.json` переносится в новый конфиг.

## Сборка

Установи JDK 25 и укажи путь к нему через `JAVA_HOME` или добавь его `bin` в `PATH`. Gradle Wrapper скачает Gradle 9.8.2 и проверит SHA-256 дистрибутива при первой загрузке. Первый запуск требует подключения к интернету для загрузки Gradle и зависимостей. Отдельная установка Gradle и папка `.build-toolchain` не нужны.

Запусти сборку из корня проекта.

**Windows (PowerShell)**

```powershell
.\gradlew.bat clean build
```

**Linux**

```sh
./gradlew clean build
```

Готовый мод появится в `build/mods/AlcoVanish-26.2-beta.jar`.
