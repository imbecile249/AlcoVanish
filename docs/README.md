# Руководство по AlcoVanish

[Установка и сборка](../README.md) · [Идеи для обновлений](ideas.md)

## Клавиши по умолчанию

Клавиши указаны по латинской раскладке. В профиле с собственными настройками назначение может отличаться.

| Клавиша | Действие |
| --- | --- |
| **K** | Открыть настройки, когда ты находишься в мире и другие экраны закрыты. |
| **H** | Переключить режим табличек. |
| **G** | Переключить подсветку игроков. |
| **N** | Переключить список ближайших игроков. |
| **V** | Переключить подсветку выбранных блоков и руд. |

Клавиши подсветки мобов и запуска или остановки рассылки изначально не назначены. Чтобы назначить клавишу, нажми поле с текущим назначением в нужной вкладке, а затем саму клавишу. **Esc** снимает назначение, пока меню ожидает нажатия.

## Таблички

1. Выбери набор стрелками у поля «Набор шаблонов».
2. Заполни одну или несколько записей. Четыре поля в записи соответствуют четырём строкам одной таблички. Кнопка с изображением таблички открывает предпросмотр, а **✕** очищает текст записи.
3. Включи «Режим табличек», закрой меню и подойди к табличке на обычное расстояние взаимодействия. Чтобы приостановить поиск новых табличек, удерживай **Shift**.

Мод выбирает ближайшую подходящую сторону таблички. Вощёные таблички и стороны с командами по клику пропускаются. При выборе шаблона мод проверяет ширину строк и старается избегать повторов надписей на соседних табличках. Текст отправляется после того, как игра разрешит редактирование. Если нужно сохранить существующую надпись, выключи режим перед тем, как подойти к ней.

На странице семь записей. **«Добавить»** создаёт запись, **«Удалить»** удаляет последнюю запись текущей страницы. В строке набора **+** создаёт пустой набор с введённым именем, **✓** переименовывает текущий, а **«Набор ✕»** удаляет текущий набор после подтверждения. **«Перезаписывать готовый текст»** позволяет повторно применить уже назначенный шаблон, если надпись позже изменится.

| Параметр | Значение по умолчанию |
| --- | --- |
| Пауза между действиями | 7–12 мс |
| Таймаут открытия редактора | 20 тиков |
| Максимум попыток для одной стороны | 2 |

Режим табличек включается вручную после входа в мир или на сервер.

### Перенос наборов

**«Экспорт»** записывает все наборы в `config/alcovanish-signs.json` и заменяет предыдущий экспорт. Скопируй этот файл в папку `config` другого профиля и нажми **«Импорт»**. Если имя уже занято и шаблоны различаются, импорт добавит к имени номер. Совпадающий набор с тем же именем пропускается.

### Команды

| Команда | Действие |
| --- | --- |
| `/signs` | Показать состояние режима. |
| `/signs on` / `/signs off` | Включить или выключить режим. |
| `/signs reset` | Сбросить состояние обработки табличек. |
| `/signs reload` | Перечитать конфигурацию AlcoVanish с диска. |

## Игроки

**«Подсветка сквозь стены»** рисует контуры игроков, которых видит клиент. Укажи радиус и при необходимости добавь ники в красный, зелёный или фиолетовый список. Ники можно разделять пробелами, запятыми или точками с запятой.

**«Список игроков рядом»** выводит ближайших игроков на HUD. Для списка отдельно задаются радиус, лимит имён и показ расстояния. В **«Настроить HUD игроков»** можно перетащить предпросмотр, изменить масштаб и непрозрачность фона.

## Мобы

Подсветка и счётчик включаются независимо. Для подсветки доступен фильтр **«Все»**, **«Дружелюбные»**, **«Враждебные»** или **«Боссы»**. Счётчик показывает общее количество и разбивку по видам. Он использует радиус из вкладки «Мобы», а свой фильтр задаётся в **«Настроить HUD счётчика мобов»**. Там же можно изменить расположение, размер, непрозрачность и мягкость краёв фона.

## Блоки

В левой колонке можно независимо отметить **сундуки** и **редстоун с механизмами**. В правой — выбрать сразу несколько видов руд или включить все. В список входят уголь, железо, медь, золото, редстоун, алмазы, незеритовые обломки, кварц, изумруды и лазурит. Варианты руд в глубинном сланце входят в соответствующие группы.

У блоков и руд отдельные ползунки **1–128 блоков**. В режиме **«Бесконечно»** подсветка охватывает доступные клиенту чанки в пределах прорисовки. Пунктир на руде отмечает обновление блока, полученное от сервера. Сам по себе пунктир не подтверждает, что руда настоящая.

## Рассылка

Введи текст длиной до **220 символов**, выбери паузу между командами и при необходимости перечисли ники в исключениях. Кнопка **«Начать для игроков онлайн»** собирает очередь из списка игроков, который сервер передал клиенту на момент запуска. Из очереди исключаются твой ник и ники из поля исключений.

Мод отправляет команды вида `/m ник текст` по одной. **«Остановить»** очищает оставшуюся очередь. Счётчик показывает, сколько команд клиент отправил. Доставку сообщений определяет сервер.

## HP

Для игроков и мобов отдельно доступны режимы **«Выкл»**, **«При наведении»** и **«Постоянно»**.

- **«При наведении»** показывает здоровье цели под прицелом. Положение, масштаб и фон панели настраиваются в одноимённом разделе.
- **«Постоянно»** показывает индикатор над сущностью. Высоту и размер можно настроить отдельно для игроков и мобов.
- Кнопка с примером индикатора переключает оформление между сердцами и полосой.

## Доп. опции

| Функция | Как работает |
| --- | --- |
| **Автоподбор инструмента** | При добыче выбирает подходящий инструмент из хотбара. Если держать кнопку добычи и навестись на следующий блок во время паузы, мод может переключить слот заранее. |
| **Автототем** | Первый тотем экипируй вручную. После его срабатывания мод пытается переложить запасной тотем из инвентаря в левую руку. |
| **Отключение тумана** | Убирает туман на экране. Загрузка чанков определяется игрой и сервером. |
| **Ночное зрение** | Осветляет мир как эффект зелья ночного зрения, пока включена галочка. |
| **Отключение темноты от вардена** | Убирает затемнение и сужение обзора от эффекта «Темнота». Сам эффект остаётся активным. |
| **Счётчик контейнеров** | Суммирует контейнеры, сломанные твоим персонажем, после подтверждения разрушения. Считает, например, сундуки, бочки, раздатчики, выбрасыватели, воронки и шалкеровые ящики. |

Число сломанных контейнеров сохраняется в настройках профиля и обнуляется кнопкой **«Сбросить счётчик»**. Галочка **«Показывать HUD счётчика»** управляет видимостью. По умолчанию HUD расположен справа, немного ниже верхнего края. Через **«Настроить HUD счётчика»** можно перетащить его, изменить размер и непрозрачность фона или вернуть исходное положение.

## Где хранятся настройки

- `config/alcovanish.json` — настройки модулей, шаблоны табличек и значение счётчика контейнеров. Если этого файла ещё нет, мод может перенести настройки из `config/nearby-workshop.json`.
- `config/alcovanish-signs.json` — файл обмена наборами табличек. Создаётся кнопкой «Экспорт».
- Назначения клавиш хранятся в настройках управления Minecraft.

Для резервной копии настроек мода сохрани `config/alcovanish.json`. Чтобы передать только наборы табличек, воспользуйся их экспортом.
